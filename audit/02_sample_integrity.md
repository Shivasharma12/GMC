## 3. Sample Integrity Violations Identified

- **[HIGH] F-04: Synthetic test fixture located in `samples/` instead of `tests/fixtures/`**
  - *Location*: [`samples/sample_gmc_policy.pdf`](file:///c:/Users/shiva/OneDrive/Desktop/assignment%20gmc/gmc-extractor/samples/sample_gmc_policy.pdf)
  - *Evidence*: `create_sample_pdf.py` in the root directory generates `samples/sample_gmc_policy.pdf`.
  - *Rule*: Per assignment instructions: "Any synthetic fixture must live only in tests/fixtures/, and its outputs must NOT be in output/."
  - *Impact*: Evaluators expecting only official test samples in `samples/` may mistake synthetic dummy PDFs for client-provided documents.
  - *Recommendation*: Move `sample_gmc_policy.pdf` to `tests/fixtures/sample_gmc_policy.pdf`, move `create_sample_pdf.py` to `tests/`, and remove synthetic outputs from `output/`.

- **[HIGH] F-05: Real official policy PDF stored in `uploads/` instead of `samples/`**
  - *Location*: [`uploads/1.Policy Copy.pdf`](file:///c:/Users/shiva/OneDrive/Desktop/assignment%20gmc/gmc-extractor/uploads/1.Policy%20Copy.pdf)
  - *Evidence*: The actual policy document provided for evaluation is in `uploads/` rather than the official `samples/` directory.
  - *Recommendation*: Copy/move `1.Policy Copy.pdf` into `samples/` so that running CLI commands like `python main.py run samples/1.Policy\ Copy.pdf` works as standard.
